# 电商用户行为分析

> 5,000 名用户 / 400 个商品 / 46,348 条订单（2024-01 ~ 2025-12）
> 工具：MySQL 8 · Python(pandas / matplotlib) · Excel

## 1. 项目背景

平台 GMV 在两年内快速增长，但管理层更关心三个问题：

1. 增长主要来自哪里？是拉新，还是老客复购？
2. 收入和用户集中在哪些城市、哪些品类？
3. 用户的复购行为如何，哪些群体值得重点运营？

本项目围绕这三个问题，完成从数据清洗、指标计算到可视化呈现的完整分析流程。

## 2. 数据说明

| 表 | 行数 | 字段 |
|---|---|---|
| users | 5,000 | user_id, register_date, city, channel, age_group |
| products | 400 | product_id, category, price |
| orders | 46,348 | order_id, user_id, product_id, order_date, quantity, amount, channel, status |

**数据质量问题及处理方式：**

| 问题 | 数量 | 占比 | 处理方式 |
|---|---|---|---|
| 重复订单（order_id 重复） | 138 | 0.30% | 按 order_id 去重，保留首条 |
| 金额缺失 | 462 | 1.00% | 不删除原始行；分析时以"有效订单"口径排除 |
| 退货记录（quantity < 0） | 231 | 0.50% | 新增 is_return 标记，GMV 计算时剔除 |
| 城市缺失 | 50 | 1.00% | 填充为"未知" |

> 说明：本项目数据为**模拟生成**，量级与真实电商一致，用于完整演示分析流程。

## 3. 分析流程

按数仓分层思路组织：

```
原始 CSV（ODS 层，保留脏数据）
        │
        ├─ users / products / orders   ← 原始表
        │
        ▼  清洗（去重、缺失、异常标记）
   orders_clean / users_clean（DWD 层）
        │
        ├─→ SQL 指标计算（GMV / AOV / 复购率 / 环比 / 新客占比）
        │
        └─→ 导出结果 → pandas 可视化 → 结论
```

**指标口径统一为：已支付订单**（不含退款、取消、退货）。

核心指标：

| 指标 | 定义 | 结果 |
|---|---|---|
| GMV | 已支付订单金额之和 | 36,093,803 元 |
| 订单数 | 已支付订单数 | 42,524 单 |
| 客单价 AOV | GMV / 订单数 | 848.79 元 |
| 复购率 | 下单 ≥2 次用户 / 下单用户 | 87.1% |
| 覆盖用户 | 有已支付订单的用户数 | 3,955 人 |

## 4. 核心结论

**① 规模持续增长，2025 年进入平台期**
月度 GMV 从 2024 年 1 月的 5.5 万元增长至 2025 年 12 月的 281.9 万元，24 个月增长约 50 倍；2025 年 9 月达到峰值 291.3 万元后趋于平稳，增长动力从"用户涌入"转向"存量经营"。

**② 收入高度集中在头部城市**
北京（645.9 万）、上海（578.8 万）、深圳（438.8 万）、广州（358.3 万）四城合计贡献约 **56%** 的 GMV。建议资源优先投放头部城市，同时评估武汉等尾部城市的获客成本。

**③ 品类结构单一，数码是绝对主力**
数码品类 GMV 1,266.7 万元，占比约 **35.1%**；家居（590.4 万）、服饰（458.4 万）、运动（443.5 万）构成第二梯队。品类集中度高，单一品类波动会显著影响整体收入。

**④ 新客占比快速下降，增长依赖老客**
新客占比从 2024 年 1 月的 100% 降至 2025 年 12 月的 0.07%，说明后期 GMV 增长主要由存量用户复购驱动（复购率 87.1%）。**这既是优势（用户黏性高），也是风险（拉新乏力）。**

## 6. 局限与改进

- **数据为模拟生成**，用户行为分布偏理想化（复购率 87% 显著高于真实电商的 30%–40%），结论仅用于验证分析流程。
- 新客占比后期接近 0，主因是模拟数据中用户注册集中在前 20 个月，**属于数据构造问题，不代表真实业务结论**。
- 未做用户分群（RFM + K-means）与流失预测，可作为下一步工作。
- 未考虑退款对 GMV 的冲减、优惠券成本等因素。
