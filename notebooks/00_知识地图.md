# 数据分析知识地图（从 0 到能做项目）

> 用法：不要背，当字典。每一条都在项目里用过一次，才算学会。
> 标记：⭐ 这周就要用 ｜ ⭐⭐ 面试常问 ｜ ○ 以后再说

## 一、整体流程（骨架，最重要）
1. 明确问题（要回答什么业务问题）
2. 取数（SQL / 导出）
3. 清洗（缺失、重复、异常、口径）
4. 计算指标（定义清楚分子分母）
5. 可视化（选对图）
6. 结论与建议（能落地）

## 二、SQL
- ⭐ 单表：SELECT / WHERE / ORDER BY / LIMIT / DISTINCT
- ⭐ 聚合：GROUP BY / HAVING / COUNT / SUM / AVG / MIN / MAX
- ⭐ 多表：INNER JOIN / LEFT JOIN / ON（注意一对多会放大行数）
- ⭐ 子查询、WITH（CTE）
- ⭐⭐ 窗口函数：ROW_NUMBER / RANK / DENSE_RANK、LAG / LEAD、SUM() OVER、PARTITION BY
- ⭐ 日期：DATE_FORMAT、DATEDIFF、按周/月分组
- ⭐⭐ 性能：索引、EXPLAIN、避免 SELECT *、WHERE 里别对字段做函数

## 三、pandas
- ⭐ 读入写出：read_csv / to_csv / to_sql
- ⭐ 看数据：shape / info / describe / head / isnull().sum() / value_counts / nunique
- ⭐ 选与筛：df[col] / df.loc[行,列] / df.iloc / 布尔条件 / isin / between
- ⭐ 清洗：drop_duplicates / fillna / dropna / astype / to_datetime / str.strip
- ⭐ 变形聚合：groupby().agg() / merge / concat / pivot_table / sort_values / rank / shift / cumsum
- ⭐ 出图：df.plot(kind=...) / plt.savefig
- ○ apply（能用向量化就别用）

## 四、numpy（最小集）
array / 向量化运算 / 布尔索引 / np.where / 聚合与 axis / nan 处理

## 五、必须懂的指标
- 规模：GMV、订单量、用户数、UV / PV
- 转化：转化率、漏斗（曝光→点击→下单→支付）
- 用户：留存（次日/7 日/30 日）、复购率、流失率
- 价值：客单价 AOV、ARPU、LTV
- 对比：同比 YoY、环比 MoM、占比
- 分布：均值 vs 中位数（长尾数据）、分位数 P50 / P90
- 异常：IQR 法、Z-score

## 六、图表选型
- 趋势 → 折线图
- 对比 → 柱状图
- 构成 → 堆叠柱（饼图少用）
- 分布 → 直方图 / 箱线图
- 关系 → 散点图
- 地域 → 地图

## 七、聚类（RFM + K-means）
- 流程：选特征 → 标准化 → 选 k（肘部法/轮廓系数）→ 聚类 → 画像 → 业务建议
- 距离：欧氏（连续、量纲统一）/ 余弦（文本、稀疏）
- 坑：不标准化会被大数值主导；k 不能只看算法，要业务能解释

## 八、统计学最小集
- 均值 / 中位数 / 标准差 / 分位数
- 相关不等于因果
- 抽样偏差、幸存者偏差、辛普森悖论（知道名字和例子即可）
- ○ A/B 测试

## 九、Excel
透视表、VLOOKUP / XLOOKUP、SUMIFS / COUNTIFS、IF / IFERROR、条件格式

## 十、新手最常踩的坑
1. JOIN 后行数变多，没检查
2. NULL 参与计算（SUM 忽略、COUNT(col) 忽略、COUNT(*) 不忽略）
3. 金额用浮点数直接比较相等
4. 去重前没搞清楚"重复"是怎么产生的
5. 分子分母口径不一致（比如 GMV 含退款、订单数不含）
6. 图表纵轴不从 0 开始，夸大差异
